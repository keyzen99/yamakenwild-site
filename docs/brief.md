# 依頼書：YAMAKEN.WILD の公式ページ（1枚）— 2026-11-13 COO

> 宛先＝新しいリポを開いたセッション（作る人）。文言と絵はオーナーと Video Maker が決める。Steve が書くのは方針・送る行動・測ること・制約だけ。
> この依頼書は、リポができたらそのリポの `.spec/` へ移し、Steve 側は要旨だけを log.md に残す（設計の正本はプロダクトのリポ）。

## 1. 目的
広告や SNS から初めて来た人が、5秒で「何者か・何をしようとしているか」をつかみ、安心して曲を聴き、Spotify でフォローする。
あわせて、ページの上の行動を Meta のピクセルで送り、広告のアルゴリズムが「曲を自分で聴いた人」を学べるようにする（2026-11-13 オーナー OK・MUS-146/147）。

## 2. 来る人
- Instagram・TikTok の広告と、ふつうの投稿のプロフィールのリンクから来る人。YAMAKEN.WILD を知らない。
- 海外（インドネシア・フィリピンなど）と日本。ほぼスマホ。

## 3. 必ず載せるもの（上から）
1. 広告と同じキービジュアル（「さっきの続きだ」と分かる絵）と名前
2. 何者かを一文、DEBUG MY LIFE が何かを一文（文言はオーナー）
3. 次の公開（NEGAU 11/27・アルバム 12/11）
4. Spotify の埋め込みプレーヤー（いま推す1曲）
5. 大きなボタンを1つだけ。公開の前は「Follow on Spotify」（Spotify の公式のアーティストのページを開く）。それ以外の時期は「Watch the MV」（YouTube）
6. 下の段に YouTube の MV、公式の SNS（Instagram・TikTok・YouTube・Spotify）へのリンク
7. いちばん下に、計測（Meta のピクセル）を使っていることを短く書く

連載の章が出るたびに、1章ずつブロックを足せる作りにする。

## 4. 作らないもの（安心感のため）
- ログイン・入力欄・メールの登録・ポップアップ
- 「あなたの Spotify のアカウントへのアクセスを許可」のような許可の画面（第三者の事前保存のサービスは使わない）
- 広告の行き先と違う見た目（最初の画面は広告の絵と同じにする）

## 5. Meta に送る行動（ピクセル・1回の訪問で各1回だけ）
| 名前（カスタムイベント） | いつ送るか | 使い道 |
|---|---|---|
| PageView | 開いたとき | 標準 |
| Read10s | 10秒以上いたとき | 件数が足りないうちの広告の目標 |
| **Listen** | Spotify の埋め込みで一定時間聴いたとき（iFrame API の `playback_update` の `position` で判定。秒数は試作で決める。ログインしていない人は30秒の試聴になる） | **広告の本命の目標** |
| SpotifyFollowClick | 「Follow on Spotify」を押したとき | 次の段の目安 |
| YouTubePlay | MV の埋め込みを再生したとき（任意） | 参考 |
| **Engaged** | Listen・YouTubePlay・YouTubeSeriesClick・SpotifyFollowClick のどれかが最初に起きたとき（1回だけ・`via` に元の行動） | **広告の目標（2026-11-17 から・MUS-149）**。Read10s は読んだだけの人に寄った・Listen 単独は件数が足りない |

- ピクセルは COO が YW の広告アカウントで作り、ID を渡す。
- 独自ドメインは Meta でドメインの持ち主として認証する（DNS の TXT）。
- 試作で必ず確かめること：Spotify の iFrame API が曲（track）でも `playback_update` を返すか（公式の説明はポッドキャスト中心）。返さなければ COO へ戻す。

## 6. 作り
- GitHub Pages。個人の GitHub（keyzen99）に新しい公開のリポを作る。Last8（last8-web・last8.jp）とは混ぜない。
- 独自ドメイン（オーナーが取得。候補は yamakenwild.com）・https。
- 静的な HTML・CSS・JS だけ。外部のライブラリは最小限。スマホで最初の画面がすぐ出ること（画像は軽く）。
- 費用はドメイン代だけ。

## 7. 言語
英語（Instagram の投稿文と同じ）。日本語を足すかはオーナーが決める。

## 8. 測ること（COO）

- Spotify のフォロワーの増え方（S4A）。続ける線＝フォロワー1人あたり ¥1,500 以下。
